## Requisitos

- `make`
- `gcc` o `clang`
- `flex`
- `bison`

**Archlinux**
```bash
sudo pacman -S base-devel
```

**Ubuntu**
```bash
sudo apt install -S build-essential flex bison
```

## Compilación

Compilación con `make`.

```bash
# mostrar ayuda
make

# compilar
make compile

# borrar artefactos de compilación
make clean
```
